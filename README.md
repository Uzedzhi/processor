Три инструмента в одном - компилятор ассемблера, видео и симулятор выполнения


### Основные фичи
  - разбиение видео на отдельные кадры
  - попиксельная компиляция видео в **собственный** язык ассемблера XXX86-64
    с **двумя** оптимизациями
  - компиляция ассемблера в **собственный** формат байт-кода.
  - Симуляция выполнения байт-кода процессором, прямо из той же программы
  - Легкий дебаг с красивым дампом и понятными сообщениями об ошибке
